# socialism-is-a-cancer

Interactive data-driven comparison of economic systems and historical outcomes. Public educational resource.

## Contents
- `index.html` — main page with sections on overview, rankings, interactive comparison, arguments, US policy shifts, and theory.
- `styles.css` — styling.
- `script.js` — client-side logic for charts and comparisons (Chart.js via CDN).

## Usage
Open `index.html` in a browser, or host as a static site (GitHub Pages enabled on main branch will serve it at the repo's pages URL).

Data is approximate and drawn from public indices (Heritage Economic Freedom, Freedom House, etc.). Sources are noted in the page. No external account linkages or personal data are included in the content.

Domain reference: socialismisacancer.com (for potential custom hosting).
